## Features

- Real-time crypto market data (Binance)
- Fiat conversion (USD / CNY / HKD)
- Dashboard overview (market cap, volume, assets)
- Kline (candlestick) visualization
- Mini trend charts (BTC / ETH / SOL)
- Data source status monitoring
- Dark-themed financial UI
